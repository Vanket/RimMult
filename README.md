# RimMult Разработка с claude

Мультиплеер для **RimWorld 1.6**: у каждого игрока своя колония (или несколько) в одном общем мире,
можно ходить друг к другу в гости, торговать и воевать. Рассчитан на 4–10 игроков и работу с модами.

Главное отличие от lockstep-мультиплеера: **каждый компьютер симулирует только свои карты**, поэтому слабый
ПК не тормозит из-за чужих колоний. Если он не тянет даже свою, её симуляцию можно передать на мощный ПК.

Подробная архитектура и план: [docs/DESIGN.md](docs/DESIGN.md).

> Статус: ранняя разработка. Готово: подключение, хост через Steam, чат, проверка модов (этап 1);
> общий мир — у каждого своя колония на одной планете, общее время с голосованием (этап 2).

## Установка

Нужен мод [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077).
Свежая сборка из `main` всегда лежит в релизе
[latest](https://github.com/Vanket/RimMult/releases/tag/latest). Установить или обновить мод
можно одной командой в PowerShell (путь к `Mods` замените на свой):

```powershell
$mods = "D:\SteamLibrary\steamapps\common\RimWorld\Mods"; $zip = "$env:TEMP\RimMult.zip"; [Net.ServicePointManager]::SecurityProtocol = 'Tls12'; Invoke-WebRequest "https://github.com/Vanket/RimMult/releases/download/latest/RimMult.zip" -OutFile $zip -UseBasicParsing; Remove-Item "$mods\RimMult" -Recurse -Force -ErrorAction SilentlyContinue; Expand-Archive $zip -DestinationPath $mods -Force
```

У всех игроков должна быть **одна и та же сборка**: RimMult сравнивает версии модов вплоть до DLL.

Чисто визуальные моды и моды интерфейса (превью карты, камера, HUD) могут отличаться: отметьте их как
«клиентские» в настройках мода RimMult. Map Preview, Camera+, RimHUD и Dubs Mint Menus/Minimap отмечены сразу.

## Структура

| Путь | Что это |
|---|---|
| `src/RimMult.Shared` | Протокол, пакеты, сериализация, координатор общего времени (`netstandard2.0`) |
| `src/RimMult.ServerCore` | Логика сервера, общая для хоста в игре и выделенного сервера (`netstandard2.0`) |
| `src/RimMult.ClientCore` | Клиентская сессия: вход, игроки, чат, время (`netstandard2.0`) |
| `src/RimMult.Net.LiteNet` | UDP-транспорт: вход по адресу и выделенный сервер (`netstandard2.0`) |
| `src/RimMult.Server` | Выделенный сервер (`.NET 10`, UDP/LiteNetLib, Docker) |
| `src/RimMult.Mod` | Сам мод (`net472`, Harmony) |
| `mod/` | Папка мода для RimWorld: `About/`, сборки попадают в `1.6/Assemblies/` |
| `tests/RimMult.Tests` | Юнит-тесты |

## Сборка

Нужен .NET SDK 10.

```sh
dotnet build -c Release     # мод соберётся прямо в mod/1.6/Assemblies
dotnet test -c Release
```

Чтобы проверить в игре, сделай ссылку на папку `mod` в `RimWorld/Mods`:

```sh
# Windows (cmd от администратора)
mklink /D "C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods\RimMult" "<путь к репо>\mod"
```

Нужен мод [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077).

## Как проверить этап 1 в игре ✅ проверено

Игра должна быть запущена через Steam. У обоих игроков должны быть одинаковые моды в одинаковом порядке.

1. В главном меню появилась кнопка **«Мультиплеер»** (после «Загрузить игру»).
2. **Хост:** «Создать игру» → вверху экрана появится полоска `RimMult: игроков 1 · пауза`.
3. **Друг:** в окне «Мультиплеер» в списке «Друзья в Steam…» появится хост → «Войти».
   Или в списке друзей Steam: правый клик по хосту → «Присоединиться к игре».
4. Оба видят друг друга в списке игроков, чат работает (в игре чат открывается клавишей **Y**,
   её можно поменять в настройках управления).
5. Проверка модов: включите у друга лишний мод — при входе он увидит, какой именно мод мешает.
6. Неверный пароль → понятное сообщение.

## Как проверить этап 2 (общий мир) ✅ проверено

1. **Хост** задаёт мир (при игре через хоста мир всегда его):
   * либо загрузите свою колонию и откройте «Мультиплеер» из меню паузы → «Создать игру» — общим станет мир этого сейва;
   * либо в главном меню «Мультиплеер» → «Загрузить сейв и создать игру»;
   * либо «Создать игру» в главном меню, а в лобби — «Создать колонию» (параметры планеты любые).
   Пока хост этого не сделал, у друга написано «Ждём, пока хост создаст мир».
2. **Друг:** «Создать колонию». Параметры планеты заблокированы («планета задана общим миром»),
   рядом с колонией хоста (ближе 4 клеток) основать не даст.
   Если у друга уже есть сейв на этой же планете, в лобби будет кнопка «Подключить этот сейв».
3. На глобусе у каждого видна колония другого (цветная иконка с именем).
4. **Время:** дата у обоих одинаковая. Скорость — по голосованию (по умолчанию идёт самая
   медленная из выбранных; пробел у любого ставит паузу всем). Вверху видно «ваш голос» и
   «ждём …», если кто-то не успевает. В лобби вверху написано «в лобби».
5. Выйти в меню и «Загрузить свою колонию» → колония продолжает с общей даты.
6. Пока у кого-то генерируется планета или грузится карта, остальных не выкидывает (ждём до 2 минут).

## Как проверить этап 3 (взаимодействие колоний) ✅ проверено

1. **Цвета.** На глобусе ваша колония и колонии других игроков окрашены в цвет игрока
   (первый — зелёный). Те же цвета у имён в лобби и чате.
2. **Посылка капсулами.** Загрузите капсулы предметами → «Запустить» → колония друга на глобусе →
   «Отправить в колонию …». У друга — капсула и письмо «Посылка от …».
3. **Переселение.** Посадите в капсулы колониста или животное и отправьте так же — у друга они
   прибудут и станут его колонистами. Или караваном: к колонии друга → «Присоединиться к колонии …».
   Караван с грузом может также «Передать груз».
4. **Обмен.** Выделите колонию друга на глобусе → «Предложить обмен». У друга появится окно
   «… предлагает вам обмен» → «Открыть обмен». Каждый выбирает слева, что отдаёт; оба жмут
   «Принять» — товары прилетят капсулами обоим.
5. **Торговля караваном.** Отправьте караван с товаром к колонии друга → «Торговать с …» (если караван
   уже там — выберите это же действие ещё раз). У друга: «Караван … прибыл и хочет торговать». Слева у вас —
   груз и животные каравана, у друга — его склады. Купленное погрузится прямо в караван, ваш товар
   спустится капсулой у колонии друга. Друг должен быть в игре.
6. **Общие поселения.** Разгромите поселение NPC — у друга оно тоже исчезнет с глобуса.
7. Если друг не в сети, посылки и переселенцы придут, когда он войдёт в мир.

## Как проверить этап 4 (кооп на одной карте) 🧪 экспериментально

Поток переделан под низкую задержку: позиции пешек ~30 раз в секунду по быстрому каналу, мелкие изменения — патчами, у гостя пакеты склеиваются за кадр. Проверьте задержку и FPS у гостя ещё раз.

1. **Режим.** Хост в окне мультиплеера выбирает «Кооп на одной карте» (под каждым режимом — описание),
   загружает свою колонию («Загрузить и хостить») или хостит из уже загруженной игры.
2. **Вход.** Друг подключается и в лобби жмёт «Войти в колонию хоста». У хоста сообщение
   «… входит в вашу колонию», мир на паузе, пока друг грузится; потом «… вошёл в вашу колонию».
3. **Видно вживую.** Друг видит, как ходят пешки хоста, как растёт стройка, появляются и исчезают
   предметы, меняются зоны, пол, крыши и туман.
4. **Приказы друга.** Друг размечает (добыча, рубка, стройка, зоны, установка), призывает пешек, отдаёт
   приказы правой кнопкой (с **Shift** — очередью), меняет приоритеты работ и исследование, атакует по цели,
   применяет способности, задаёт цель турели — у хоста это выполняется, у друга результат появляется через
   долю секунды.
5. **Настройки друга.** Счета на верстаках, настройки складов и зон, выбор растения, владелец кровати,
   расписание, политики (одежда, препараты, еда) и их назначение пешкам, разрешённые области — у хоста
   меняется то же самое.
6. **Трупы** убитых животных и людей видны другу (раньше пропадали), с крестиком «запрещено».
7. **Глобус.** Друг видит, как едут караваны колонии, может сформировать караван (окно «Сформировать
   караван»), отправить его правой кнопкой по глобусу, выбрать пункт меню (зайти в поселение, напасть…).
8. **Новые карты и квесты.** Хост вошёл на точку квеста, попал в засаду, перелетел гравикораблём — у друга
   сообщение «Хост открыл новую карту» и игра сама загружается заново (с паузой у всех), закрытые карты
   исчезают. Квесты общие: вкладка «Задания» у друга такая же, как у хоста, и друг может принять квест.
9. **Скорость** — голосованием, как раньше: кнопки скорости у друга — это его голос.
10. Хост вышел — у друга окно «Связь с хостом потеряна» (главное меню или остаться в копии).

Пока не работает у гостя: операции, разделение каравана — подробности в `docs/DESIGN.md`.

## Как проверить этап 5 (дипломатия и PvP)

1. **PvP включено.** У хоста в окне «Хост» (режим «Раздельные колонии») галочка «Разрешить войны
   между игроками (PvP)» — по умолчанию включена.
2. **Война.** На глобусе выделите колонию друга → «Дипломатия» → «Объявить войну». У друга письмо
   «… объявил войну», в лобби рядом с именем — красное [война]. Торговля между вами отключится.
3. **Рейд караваном.** Соберите караван с вооружёнными колонистами → ведите к колонии друга →
   «Отправить рейд на … (ведёт ИИ)». У друга с края карты войдут ваши колонисты как рейд (письмо «Рейд
   игрока …»). Его игра ведёт бой: ваши пешки штурмуют, воруют, похищают, отступают.
4. **Рейд лично.** Тот же караван → «Напасть лично на …». Ваша колония сохранится, загрузится колония друга
   (у всех пауза на время загрузки), и вы управляете своими бойцами: призыв, приказы правой кнопкой, Shift,
   атака по цели, способности, кнопки «Отступить», «Похитить», «Украсть», «Вернуться домой». Друг в это время
   обороняется сам и не видит ваших приказов и выделения. Когда бой закончится, у вас снова загрузится ваша
   колония, выжившие придут караваном. Если выйти раньше — рейдом доуправляет ИИ.
5. **Десант.** Загрузите колонистов в транспортные капсулы → запуск → колония друга →
   «Десант в капсулах на …» (ведёт ИИ или лично).
6. **Итоги.** Когда бой закончится: у друга письмо «Рейд … закончился» (кто убит, кто ранен, что украли);
   у вас — караван выживших у колонии друга с добычей и пленными и письмо с итогами.
7. **Мир / союз.** «Дипломатия» → «Предложить мир» (во время войны) или «Предложить союз» —
   у друга окно «Принять / Отказаться».
8. **Помощь союзнику лично.** Караван (или капсулы) к колонии союзника → «Помочь лично: …». Ваши люди
   приходят туда, где сейчас союзник (его колония или точка квеста), а вы загружаете его игру и командуете
   ими рядом с его людьми — вместе проходите квест или отбиваете рейд. Союзник вашими людьми командовать не
   может. «Вернуться домой» — загрузится ваша колония, люди вернутся капсулами.
9. Напасть можно только на игрока, который сейчас в мире; если он вышел, отряд вернётся домой.
10. Исчезнувшее поселение NPC исчезает у всех. С модами, которые сами воюют на глобусе (Rim War, Dynamic
    Diplomacy), общими остаются только поселения, разгромленные игроком, — их войны меняют глобус только у того,
    у кого они идут.

Если что-то не так — пришлите `Player.log`
(`%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\Player.log`), строки с `[RimMult]`.

## Моды

Моды должны совпадать у всех (интерфейс, звук, текстуры и переводы можно отметить «только у меня» в
настройках RimMult). Рассинхронов из-за модов нет — каждая игра симулирует своё сама. Разбор совместимости
большой сборки (310 модов) и что убрать — в [`docs/MODS.md`](docs/MODS.md). Мод **Multiplayer** (Zetrith)
с RimMult не работает. Авторам модов — [`docs/API.md`](docs/API.md).

В коопе данные модов (сети труб, переключатели и т. п.) хост передаёт гостям сам, а раз в секунду сверяет вещи
на карте и чинит расхождения. Если у гостя что-то не так — «Загрузить заново» в окне мультиплеера. Для багов —
кнопка «Отчёт об ошибке»: файл с версиями, модами и ошибками.

## Выделенный сервер

```sh
docker compose up -d                                          # Docker: мир, конфиг и бэкапы в ./server-data
docker attach rimmult                                         # консоль: help, players, kick, ban, say, pvp…
# или готовая сборка из Releases, или из исходников:
dotnet run -c Release --project src/RimMult.Server            # создаст server.json с настройками по умолчанию
```

Команды, баны, админы, автобэкапы — в [`docs/SERVER.md`](docs/SERVER.md). Админские команды работают и в чате
игры у хоста: `/kick`, `/ban`, `/say`, `/pvp off`… Публикация в Steam Workshop — [`docs/WORKSHOP.md`](docs/WORKSHOP.md).
