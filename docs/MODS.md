# Совместимость модов с RimMult

## Как RimMult обращается с модами

RimMult не держит игры в «замке» (lockstep), как мод Multiplayer (Zetrith): каждая игра симулирует своё сама, а
другим передаётся состояние (сохранённые объекты, позиции, приказы). Поэтому:

* **Рассинхронов из-за модов нет.** Случайности, оптимизации тиков, свои системы модов не обязаны совпадать
  между компьютерами.
* **Моды должны совпадать у всех** (сервер сверяет список и версии): предметы, пешки и постройки из модов
  переходят между играми целиком. Моды только для интерфейса, звука, текстур и переводы можно отметить
  «только у меня» в настройках RimMult — тогда они могут отличаться.
* **Слабые места**: моды, которые сами меняют скорость игры; моды со своими системами вне вещей (сети труб,
  хранилища в компонентах карты) — у гостя коопа их значения могут отставать (симулирует всё равно хост);
  моды, отдающие приказы в обход меню/кнопок/дезигнаторов, — у гостя коопа такие приказы не доходят до хоста.

## Разбор списка (310 модов)

### 🔴 Убрать

| Мод | Почему |
|---|---|
| **Multiplayer** (2606448745) | Другой мультиплеер: переписывает те же части игры (тики, приказы, сохранения). Вместе с RimMult не работает — RimMult при запуске покажет предупреждение. |
| **Smart Speed** (1504723424) + перевод | Сам меняет скорость игры и кнопки скорости, а в RimMult скорость — общее голосование: мод будет «голосовать» за игрока и спорить с сервером. |
| **Дубли SRTS Expanded** (1845423808, 2878587061, 2938738526) | Три версии одного мода — оставьте одну для 1.6. |
| **Дубли Dynamic Diplomacy** (1875168898 и 3220299022, переводы 3286502479 и 3555643205) | Старая и Continued одновременно — оставьте Continued и один перевод. |
| **Дубли Replace Stuff** (1372003680 и 3526354009) | Две версии — оставьте одну. |

### 🟠 Работает с оговорками

| Мод | Что учесть |
|---|---|
| **FPS Stabilizer** | Урезает тики ради FPS: общая скорость мира подстраивается под самый слабый ПК, весь мир будет медленнее. Лучше выключить. |
| Performance Optimizer, Slower Pawn Tick Rate, Ideo Tick Optimization, Performance Esmolas, Missile Girl Performance | Рассинхрона нет (нет lockstep). Должны быть у всех одинаковыми или отмечены «только у меня». |
| **Vehicle Framework + Vanilla Vehicles Expanded** (Tier 3, Upgrades) | На своей карте — нормально. Сама техника в чужую игру не уходит (особые пешки со своими сетками пути): RimMult её не пускает ни в посылки, ни в переселение, ни в помощь. **Рейд на технике:** доезжаете караваном с машинами до колонии врага → «Рейд на технике» — машины с экипажем внутри въезжают с края карты и атакуют под ИИ Vehicle Framework (как машины NPC-рейдеров; в «лично» вы командуете пешими, техникой правит ИИ), выжившие машины возвращаются караваном. Или «… — только экипаж»: в бой уходят люди, техника с грузом ждёт у колонии, выжившие садятся обратно. В коопе у гостя техника может отображаться неточно. |
| **Rim War**, **Dynamic Diplomacy** | Пока они включены, общими между игроками остаются только поселения, разгромленные игроком: их войны меняют глобус только у того, у кого они идут. Без них любое исчезнувшее поселение NPC исчезает у всех. Тяжёлый для ПК. В коопе армии на глобусе гостя появляются/исчезают, но не едут плавно. Проверьте, что версия под 1.6. |
| **DeepRim**, **Vanilla Gravship Expanded / гравикорабли Odyssey** | Каждый подземный уровень / перелёт — новая карта: в коопе у гостя игра каждый раз сама перезагружается (с паузой у всех). В раздельных колониях — без ограничений. |
| **SRTS Expanded, Shuttle Dock, шаттлы Odyssey** | Шаттлы Odyssey и Royalty везут посылки, рейды и помощь к игроку, как капсулы: люди и груз уходят, сам шаттл возвращается домой пустым. Летающая техника Vehicle Framework и SRTS — нет (у них своё меню прибытия). |
| **InterRim Ballistic Missile** | По колонии врага (война, PvP, он в мире) — можно: ракета долетает до его значка на вашем глобусе, и мод у него запускает такую же ракету со стороны вашей колонии (видна на его глобусе, ПВО может сбить, падает на его базу). Тактической ракетой клетку не выбрать — точку удара выбирает игра защитника. Мод должен быть у всех. |
| **Achtung!, Group Actions, MultiConstruction, MultiTending, Move the Patient, Arrest Here!, Defensive Positions** | У хоста и в раздельных колониях — полностью. У гостя коопа приказы этих модов в обход обычных меню (строй Achtung, «принудительная работа») до хоста не доходят — пользуйтесь обычными приказами. В «рейде лично» и «помощи лично» приказы Achtung работают (они передаются как работы пешек). |
| **RunAndGun, Search and Destroy** | Переключатели на пешках у гостя коопа срабатывают у хоста, но у гостя кнопка может показывать старое состояние. |
| **Dubs Bad Hygiene, Rimefeller, Rimatomics, Replimat, Project RimFactory (+Insanity), LightsOut, газ/химтопливо/паста VE** | Свои сети (трубы, реакторы). В коопе у гостя значения в сетях могут отставать — симулирует хост, на игру не влияет. RimFactory постоянно меняет машины — больше трафика в коопе. |
| **Adaptive Storage Framework, Autoshelf, Neat Storage, Fridge, Reel's Expanded Storage** | Настройки складов у гостя коопа синхронизируются; содержимое необычных хранилищ у гостя может обновляться с задержкой. |
| **Vanilla Psycasts Expanded** (+Hemosage, Puppeteer) | Пси-способности — свои способности VE; у гостя коопа и в «рейде/помощи лично» передаются через общий перехват прицеливания. Способности с двумя целями (сначала цель, потом точка) пока не работают у гостя. |
| **Cheat Menu** | Работает. В PvP это читы — договоритесь. |
| **Dubs Mint Menus** | Заменяет меню; если у гостя коопа какое-то действие не доходит до хоста — проверьте без него. |

### 🟢 Без проблем

* **Весь Vanilla Expanded** (фреймворк, мебель, оружие, броня, фракции, расы, кухня, квесты, идеология,
  генетика, аспирации, навыки и т. д.), **Zoology, ISEKAI RPG Leveling, Fortifications/Fortified Features,
  Reinforced Walls, Dub's Paint Shop, Dubs Skylights, Dubs Apparel Tweaks, Dubs Break Mod, Rimkit, HugsLib,
  Harmony, Prepatcher, Pick Up And Haul, Allow Tool, Replace Stuff (одна версия), Smarter Construction /
  Deconstruction, Smart Farming, Door Clearance, Easy Upgrades, Increased Stack, Yayo's Caravan, Better Traders,
  Universal Trade Hub, Dynamic Diplomacy (одна версия), Empire Refactored, World Tech Level, Map Designer,
  Geological Landforms, Base Generation, Map Reroll, Choose Where To Land, EdB Prepare Carefully, Pawn Target Fix,
  SimpleBabyCarry, Food Restriction Eleven, Vanilla Research Panel** — контент и игровые системы, должны быть у
  всех одинаковыми (сервер это проверит).
* **Можно отметить «только у меня»**: все **русификаторы**, Camera+, RimHUD, Interaction Bubbles, P-Music,
  Dubs Mint Minimap, Dubs Performance Analyzer, Map Preview, Blood Animations, Muzzle Flash, Yayo's Animation,
  Vanilla Pawns Retextured, Bionic icons, Nice Bill Tab / Inventory Tab / Plants Menu, Auto links, Aligned
  Turbines, ретекстуры (шаттл, карьер).

## Что проверить в игре

1. Убрать красные, запустить у обоих одинаковый список (сервер покажет, чего не хватает).
2. Кооп: призыв, Shift-очередь, счета на верстаке (в т. ч. через Nice Bill Tab), склад Adaptive Storage,
   пси-способность VPE у гостя.
3. Раздельные колонии: рейд лично и помощь лично с одним-двумя колонистами без техники.
