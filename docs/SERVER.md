# Выделенный сервер RimMult

Сервер для режима «раздельные колонии» (кооп требует хоста в игре). Держит общий мир: планету, колонии игроков,
мировое время, почту посылок, дипломатию. Сама игра у каждого игрока своя, сервер её не симулирует, поэтому ему
хватает самого слабого VPS.

## Запуск

**Готовая сборка** (вкладка Releases на GitHub, архив `RimMult-Server-…-linux-x64.zip` или `win-x64.zip`):
распакуйте и запустите `RimMult.Server` (`RimMult.Server.exe`). При первом запуске появится `server.json` с
настройками по умолчанию; пример с комментариями — `server.example.json`.

**Docker** (из корня репозитория):

```sh
docker compose up -d        # первая сборка образа, затем запуск в фоне
docker attach rimmult       # консоль сервера: команды ниже; выйти не останавливая — Ctrl+P, Ctrl+Q
docker compose logs -f      # лог
docker compose down         # остановить (мир сохранится)
```

Мир, `server.json` и бэкапы лежат в `./server-data`. Имя, пароль, лимит и PvP можно задать переменными окружения
в `docker-compose.yml` (`RIMMULT_NAME`, `RIMMULT_PASSWORD`, `RIMMULT_MAXPLAYERS`, `RIMMULT_PVP`, `RIMMULT_PORT`)
— они главнее файла и в него не записываются.

**Из исходников**: `dotnet run -c Release --project src/RimMult.Server`.

Откройте/пробросьте на роутере **UDP 26480** (или порт из `server.json`). Игроки подключаются в окне мультиплеера
по адресу `IP:порт`.

## Команды

В консоли сервера — просто текстом; в чате игры — с косой чертой (`/kick Вася`). В чате команды доступны хосту и
админам (`admin <игрок>`); `help` и `players` — всем. Ответ видит только тот, кто спросил.

| Команда | Что делает |
|---|---|
| `help` | список команд |
| `players` | кто на сервере (id, SteamID, в мире или в лобби) |
| `kick <игрок> [причина]` | выгнать (игрок — `#id`, SteamID, имя или начало имени) |
| `ban <игрок\|SteamID> [причина]` | выгнать и не пускать |
| `unban <SteamID>`, `bans` | вернуть доступ; список банов |
| `admin <игрок\|SteamID>`, `unadmin …` | дать/забрать админские команды в чате |
| `say <текст>` | объявление всем в чат |
| `pvp on\|off` | разрешить/запретить войны и рейды (сразу у всех) |
| `password <текст>\|off` | пароль для новых подключений |
| `maxplayers <n>` | лимит игроков |
| `save` | сохранить мир сейчас (только выделенный сервер) |
| `backup` | бэкап мира сейчас (только выделенный сервер) |
| `stop` | сохранить и остановить (только выделенный сервер) |

Баны, админы, пароль, лимит и PvP, изменённые командами, сохраняются в `server.json`.

## Бэкапы

Каждые `BackupIntervalMinutes` минут (по умолчанию 30) мир копируется в `BackupDirectory`
(`backups/world-ГГГГММДД-ЧЧММСС.dat`), старше `BackupsToKeep` (48 — сутки) удаляются. Восстановить: остановить
сервер, скопировать нужный бэкап поверх `world.dat`, запустить.

Мир сохраняется сразу при изменении колоний и не реже раза в 30 секунд, через временный файл — обрыв питания не
оставит его обрезанным.
