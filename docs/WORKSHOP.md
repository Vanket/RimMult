# Публикация в Steam Workshop

Мод опубликован: https://steamcommunity.com/sharedfiles/filedetails/?id=3813029532 — номер лежит в
`mod/About/PublishedFileId.txt`, поэтому загрузка из игры обновляет этот предмет. Для обновления: новый тег →
архив из Releases → заменить папку в `RimWorld/Mods` → «Загрузить в Мастерскую Steam».

## Подготовка

1. Поставить тег версии: `git tag v0.5.0 && git push origin v0.5.0` — GitHub Actions соберёт релиз
   (архив мода и сервер для Linux/Windows) в Releases.
2. Распаковать `RimMult-v0.5.0.zip` — получится папка `RimMult` с `About/About.xml`, `About/Preview.png`,
   `1.6/Assemblies/RimMult.dll`, переводами.

## Через игру (проще)

1. Положить папку `RimMult` в `RimWorld/Mods`, включить мод.
2. Включить режим разработчика (Настройки → «Режим разработки»).
3. Главное меню → «Моды» → выбрать RimMult → кнопка «Загрузить в Steam Workshop» (появляется в режиме
   разработчика). Принять соглашение мастерской.
4. Игра создаст `About/PublishedFileId.txt` с номером предмета — **сохраните его в репозиторий**
   (`mod/About/PublishedFileId.txt`), тогда следующие загрузки обновят тот же предмет, а не создадут новый.
5. На странице предмета в Steam: описание, скриншоты, видимость (сначала «Скрыто» или «Только друзья»,
   проверить подписку с другого аккаунта, затем «Публично»).

## Через steamcmd

Шаблон — `tools/workshop/rimmult.vdf`: прописать пути к папке мода и превью, при обновлении — номер предмета в
`publishedfileid`, затем:

```sh
steamcmd +login <аккаунт> +workshop_build_item /полный/путь/rimmult.vdf +quit
```

## Перед публичным релизом

* Версия в `Directory.Build.props` и `mod/About/About.xml` совпадает с тегом.
* Протокол (`ProtocolInfo.Version`) поднят, если менялся формат пакетов: игроки с разными версиями мода не
  подключатся друг к другу (увидят понятное сообщение).
* Зависимость Harmony указана в `About.xml` (Steam предложит подписаться на неё), несовместимость с модом
  Multiplayer (Zetrith) — тоже.
